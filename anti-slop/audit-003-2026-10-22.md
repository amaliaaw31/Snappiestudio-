# Audit tombol mode gelap CMS

Mode `after` mengikuti pilihan pengguna dalam sesi ini. Lingkup: tombol tema pada login dan dashboard, penyimpanan preferensi, serta pembaruan warna diagram. Arah visual mempertahankan identitas Snappie dan dial ENERGY 1 / RHYTHM 2 / MOTION 1. Permukaan gelap melayani pilihan admin; aksen merah muda tetap menandai batang data dan aksi utama. Tidak ada temuan baru pada lingkup yang diuji.

Sebelum memilih tema, CMS mengikuti preferensi sistem. Tombol `Mode gelap` memakai `aria-pressed` untuk menyatakan keadaan. Pilihan manual tersimpan khusus CMS dan berlaku pada login serta dashboard. Skrip eksternal kecil diterapkan sebelum stylesheet agar warna tersimpan tersedia sejak awal pemuatan. Jika penyimpanan browser diblokir, tombol tetap bekerja selama halaman terbuka. Tidak ada perubahan CSP, autentikasi, backend, atau dependensi.

## Delivery Gate

- Hard Gate PASS: tombol benar-benar mengubah tema, dapat dipakai dengan Enter, dan memiliki fokus terlihat. Teks tombol serta deskripsi memenuhi kontras 4,5:1 pada kedua mode. Halaman tidak meluber pada lebar 320, 390, 768, dan 1440 piksel.
- Purpose-Gate PASS: kontrol berada pada header agar pilihan berlaku untuk seluruh halaman. Border berwarna hanya menandai tombol yang aktif. Tidak ada ikon, gambar, glow, gradient, atau animasi baru.
- Liveliness PASS: dial 1/2/1 dan hierarki CMS dipertahankan. Warna berasal dari token terang/gelap yang sudah ada; tidak menambah palet baru.
- Craftsmanship PASS: lint, 72 tes termasuk keamanan, build, dan pemeriksaan diff lulus. Skrip tema baru tercakup dalam lint.

## Bukti browser

Skrip `/tmp/snappie-verify-cms-theme.mjs` memakai backend, akun, dan database lokal khusus tes. Seluruh pemeriksaan berikut lulus:

- Preferensi awal mengikuti sistem terang dan merespons perubahan sistem ke gelap.
- Pilihan manual terang dapat menimpa sistem gelap dan bertahan setelah reload.
- Enter mengaktifkan mode gelap dengan `aria-pressed=true` dan outline fokus terlihat.
- Tema gelap bertahan dari halaman login ke dashboard dan saat logout.
- Tombol dashboard mengubah tema; hasil gambar Canvas berubah setelah pemilihan manual, membuktikan diagram digambar ulang.
- Perubahan sistem tidak menimpa pilihan manual.
- Kedua mode dashboard memenuhi pemeriksaan overflow dan kontras pada empat ukuran viewport.
- Header login dengan tombol tema tetap muat pada lebar 320, 390, dan 1440 piksel.
- Tombol tetap berfungsi ketika pembacaan dan penulisan localStorage gagal.
- Tidak ada exception browser yang tidak tertangani.

Deploy menyalin build ke `/var/www/snappie`. HTML login, CSS, dan skrip tema produksi dibandingkan dengan sumber dan identik. Chrome produksi memverifikasi tombol gelap, pilihan tersimpan setelah reload, dan kolom username tetap kosong. Backend tidak perlu direstart sehingga sesi admin yang ada tetap berlaku.

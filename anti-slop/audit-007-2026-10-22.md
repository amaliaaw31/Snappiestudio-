# Audit fitur operasional dan laporan CMS

Mode after mengikuti pilihan sesi. Lingkup merupakan seluruh 15 fitur yang dipilih pengguna. Arah tetap dashboard Snappie compact dengan ENERGY 1 / RHYTHM 2 / MOTION 1. Fitur laporan berada di Ringkasan/Kunjungan; formulir, riwayat, dan status berada dalam details pada Pengaturan. Tidak ada aset visual baru.

- Hard Gate PASS: kalender memakai browser unik harian sebenarnya; angka baru/kembali mengikuti filter. Tabel tren mengikuti interval grafik. Pengumuman ditulis dengan textContent, bukan innerHTML. Semua status eksternal membedakan belum dikonfigurasi, gagal, dan berhasil. Formulir memiliki label dan keadaan memuat/gagal. Dialog reset memiliki fokus, input konfirmasi, batal, dan Escape native. Browser membuktikan pengaturan terbuka tidak meluber pada 320/390/768/1440 piksel pada kedua tema; navigasi tiga halaman tetap lolos pada 320–1920 piksel.
- Purpose Gate PASS: intensitas kalender menunjukkan jumlah aktivitas, tanpa menyampaikan fakta hanya lewat warna karena angka tetap tersedia. Dropdown wilayah berasal dari lokasi nyata. Dialog cetak memakai browser native; tema cetak terang sementara menjaga kontras grafik. Tidak ada badge, ikon, dekorasi, atau dependensi baru.
- Liveliness PASS: dial 1/2/1, wordmark dan simbol tema Snappie tetap dipakai. Hierarki angka dan grafik menjadi fokus; informasi tambahan dibuka sesuai tugas admin.
- Craftsmanship PASS: lint, 100 tes, build, audit dependensi, validasi unit systemd, dan diff check lulus. Browser memeriksa filter provinsi, preferensi setelah reload, kalender, perbandingan wilayah, PDF nyata, sesi terpilih, audit, arsip, status server, pengumuman, serta reset data sintetis. Pengumuman berisi string HTML diuji tetap berupa teks dan dapat ditutup. Regresi akun mengulang 2FA, pemulihan, perubahan password dan logout. Worker backup CLI diuji untuk mencegah siklus impor yang menghambat eksekusi terjadwal.

Backend menambahkan tabel audit dan arsip tanpa menghapus kunjungan atau akun. Backup produksi dibuat dan diuji sebelum migrasi. PDF sintetis berada di `/tmp/snappie-report-synthetic.pdf`; tidak berisi data produksi.

Backup luar server dan notifikasi mempunyai implementasi serta tes enkripsi/pengiriman, tetapi tujuan dan kredensial belum disediakan. Pengujian unggahan/notifikasi menggunakan pengganti lokal, bukan klaim pengiriman ke layanan nyata. UI secara eksplisit menampilkan belum dikonfigurasi. Pemantauan di host yang sama juga tidak menggantikan pemeriksaan uptime dari luar host. Prosedur aktivasi dan pemulihan berada dalam SECURITY.md.

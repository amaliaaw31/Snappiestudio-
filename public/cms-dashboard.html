        Reset data kunjungan
        Hapus seluruh data kunjungan dan aktivitas. Riwayat admin dan pengecualian browser tetap disimpan.
        
      
        Bot Discord dan jadwal migrasi
        Gunakan /pengumuman untuk mengatur pengumuman manual. Gunakan /migrasi jadwalkan untuk pengingat dan pengumuman otomatis dalam WIB. Bot tidak memindahkan data server.
          
      
          Pengumuman situs
        
          Kosongkan jadwal untuk menampilkan pengumuman selama kotak di atas dicentang. Pengumuman otomatis berhenti tampil setelah waktu selesai.
          
      
          
      
          Musim stiker
        
          Atur kapan tiap grup stiker musiman tampil sebagai "Sekarang". Otomatis memakai tanggal bawaan; isi tanggal mulai dan selesai untuk menggantinya tahun ini, misalnya tanggal Lebaran. "Selalu tampil" memaksa aktif dan "Sembunyikan" menghilangkan grup dari menu stiker. Tanggal hanya berlaku pada mode Otomatis.
          
        
          
        
          
      
          
      
          Tautan dukungan
        
          Popup dukungan muncul setelah pengunjung mengunduh PNG, sebelum pertanyaan "Mau jepret lagi?". Hanya alamat trakteer.id dan ko-fi.com yang diterima. Kosongkan kolom untuk menyembunyikan tombolnya.
          
        
          
        
          
      
          
      
          Riwayat aktivitas admin
          Menyimpan maksimal 10.000 kejadian selama 90 hari. Password, kode autentikator, dan IP tidak dicatat.
            
      
            Laporan mingguan dan bulanan
            Ringkasan periode yang sudah selesai dibuat otomatis tiap hari. Pilih laporan untuk membaca atau mengunduh salinannya. Data sebelum awal pencatatan bisa belum lengkap.
            
      
            Status layanan dan pemantauan
            
      
            Pemulihan akun
            1. Jika autentikator hilang, gunakan satu kode pemulihan pada langkah kedua login.
            2. Setelah masuk, buka Akun dan keamanan. Gunakan password saat ini dan kode pemulihan lain untuk menonaktifkan 2FA.
            3. Daftarkan autentikator baru, lalu simpan set kode pemulihan baru di tempat terpisah.
            4. Jika semua kode hilang, hubungi pengelola server. Pemulihan memerlukan verifikasi pemilik dan backup akun yang cocok. Halaman publik tidak menyediakan pintasan login.
            
      
            
        Cadangan dan data lokasi
        
            Cadangan harian pukul 02.30 WIB, menyimpan 14 salinan terakhir. Setiap cadangan diuji dengan pemulihan ke direktori sementara. Data lokasi diperbarui setiap tanggal 2 pukul 04.00 WIB.

            Total menghitung satu browser sekali. Statistik periode menghitung browser yang berkunjung dalam periode tersebut, termasuk yang kembali.

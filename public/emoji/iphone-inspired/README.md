# Original iPhone-inspired emoji

120 original emoji generated with the built-in image_gen tool for Snappie Studio.
These are original illustrations inspired by the shaded mobile emoji style, not Apple artwork.

Six transparent PNG atlases each contain 20 emoji in a 5-column, 4-row layout.
The catalog is in `src/emoji-catalog.js`; `src/emoji.js` supplies shared preview and Canvas rendering.
Generation prompts are recorded in `docs/emoji-artwork-prompts.json`.

Used only by Add Sticker and the corresponding sticker previews/PNG exports.

# Localized emoji labels

`src/emoji-locales.js` contains names and search keywords for the 120 emoji used by Snappie Studio, in its 16 supported languages.

Source: Unicode CLDR JSON, `cldr-json/cldr-annotations-full/annotations/{locale}/annotations.json` in [unicode-org/cldr-json](https://github.com/unicode-org/cldr-json), retrieved on 2026-10-22. Only the selected emoji annotations are included. Variation selectors were normalized when matching annotations to the existing artwork.

The data is distributed under Unicode License V3; see `CLDR-LICENSE.txt`. The original artwork and its license are documented separately in `iphone-inspired/README.md`.

Labels and search keywords are bundled locally. No translation service receives searches, photos, or other visitor data.
